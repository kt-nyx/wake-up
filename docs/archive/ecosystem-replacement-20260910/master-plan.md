## Defaults and product boundaries

Prepatcher remains required. Existing supplier integrations remain optional.
Existing defaults remain; translation, image/prepared caches, routing, deferred
audio, streaming XML, display/diagnostics, background loading, summary hiding and
per-mod timings default off. Native preparation preserves quality. Windows
full/half/quarter exports are explicit color-artwork choices and can change pixels;
they are not injected game textures or full converter parity.

Automatic PNG/JPEG gets 512 MiB. Native preparation and DDS exports share another
512 MiB; complete entries are limited to 8 MiB. No extra cache category or default
change is awaiting approval in this campaign. R3 experimental acceptance retains
its documented bypass/drain/worker limitations; it is not a universal-safe fallback
or release qualification. Feature overlap does not prove a supplier removable.

## Validation and release decisions

Use proportional combined offline checks and one bounded independent integration
review. Fix material findings before building stable committed source. Include
matching source/notices with a verified optional Windows helper. Keep private
fixture/observer binaries out of runtime; tracked test/experiment source may be
included in the source archive. New release/platform/ordinary-entry qualification
flags must remain false. Documentation closeout need not rebuild merely to match HEAD.

Further qualification requires its own scope. F1 covered bounded English
functional paths. French, broader first-construction/reuse coverage, ordinary
colony entry/preferences/pause/abort and actual screens remain separate work.
Performance claims need
matched old public/pre-campaign/new/absent controls with stable content and forward/
reverse order. Supplier absence can answer a delivered feature question, not prove
missing independent XML was replaced. Diagnostic timings are not complete startup.
