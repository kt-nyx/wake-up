## Defaults, dependencies and limits

Existing definition/template/type search and ordinary supplier defaults remain.
Required Prepatcher remains; Gagarin, Character Editor, Loading Progress and
Giddy-Up are optional. Master-disable wins ordinary activation; explicit fixture
controls retain their separate precedence. New choices default off: translation
application, automatic PNG/JPEG reuse, native prepared use, texture-supplier
routing, streamed audio, streaming XML, loading display/diagnostics, background
loading, summary hiding and per-mod XML timings. Preparation runs only by explicit
menu action; export choices return to native preservation when the window reopens.

Automatic PNG/JPEG has 512 MiB. Native prepared entries and portable DDS exports
share another 512 MiB, including mappings and interrupted/replacement output;
complete entries are capped at 8 MiB. There is no third allowance. Only successful
native prepared publication/restoration retires the exact matching automatic key.
Exports cannot be read as native prepared textures. Native preparation retains
the actual game's quality; Windows full/half/quarter DDS exports can change pixels
and require a separate suitable-color acknowledgement and consumer review.

The unchanged helper has stdio-v2 and exact output-contract checks, one owned
child per item, bounded input/output and 256 MiB private process memory limit.
R5 verifies all 13 tracked source/build inputs, binary, notices and pinned
dependency archive hashes before reusing it. The old build receipt identifies a
dirty R2 build checkpoint; input hashes, not that old HEAD label, establish its
match to the committed source supplied with rc.2. No Linux binary is built or
included. Core/native preservation does not require the helper.

R3 audio remains experimental/default-off. Supported first use is a main-thread
request through the bounded compiled consumer/holder family. Arbitrary reflection
or generated code can bypass rewritten reads; worker first use is unsupported.
A bypassing read before a worker-requested main-thread drain can see an unassigned
song field. This accepted limitation is neither concealed nor expanded into a
blanket reflection-interception project. Native playback, smooth first use and
actual Mono/Prepatcher behavior remain unqualified.

R4a streams XML input with native workers/order/fallback; it does not cache
completed XML. Independent XML/parsed-language reuse remains missing. R1's
769.6 ms reuse versus 22.1 ms native and R4b's 37.204 ms warm versus 13.194 ms
native were losing CPU experiments. R4c's revised language route lost 6/12 pairs
and was not integrated. Native GenTypes/construction delegates already cache.
No redundant cache or unchanged rejected route was reopened.

General deferred/progressive textures, grouped stores, completed atlases,
broad automatic image formats/first-build replacement, full profiling, standalone/
pocket-map and general background-event coverage remain absent. The
[scope table](retained-features.md#every-original-goal-and-its-disposition) tracks
all nine original goals plus S14 and recovered BetterLoading ideas. These are
documented missing capabilities, not remaining R5 implementation blockers.
