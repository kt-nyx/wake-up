## What changes from the last actual release

Compared locally against the actual `v0.2.1` tag, the candidate adds processed-XML
reuse, translation application, additional code-type and reflection search reuse,
asset routes, extended XML-query handling, JPEG alongside PNG output reuse, optional
PSD decoding, explicit texture preparation/quality/reset controls, and a loading
display/reports plus loading-only background behavior. The shared cache budget defaults to
1 GiB and is adjustable; public 0.2.1's PNG budget defaulted to 512 MiB. Optional new controls default off, but
new search reuse under the existing default-on type-search setting is active by
default; saying that *all* additions default off would be inaccurate.

Prepatcher was already required. Supplier mods remain optional; unchanged
Character Editor, Giddy-Up and Loading Progress integrations are retained, and
Gagarin integration accommodates Wake-Up's optional streaming constructor. The Windows
helper is optional and used for explicit quality conversion/DDS export. Native
PNG/JPEG reuse needs no helper. Quality choices can change pixels and dimensions,
apply after restart and preserve original mod files. The retired experimental routes
were not public 0.2.1 features, so their retirement does not remove released features.
Streaming XML remains experimental; C10/C11/companion remain deferred.

The practical release difference is more optional loading tools and supported
reuse paths, with costs stated above. It is not a large general default speedup.
